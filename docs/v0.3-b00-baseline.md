# v0.3 B00 baseline and interface audit

Audited on 2026-10-24 before implementation. The source baseline was clean:

- HEAD: `4093f960839e367dfd98c033d060040c4aabd7e8` (`main`, tag `v0.2.2`)
- Remote: `origin https://github.com/hail7723/deepseek-longtime-plugin.git`
- User data was not opened or migrated during B00. The live v1 database remains at `.deepseek-memory/memory.sqlite`.
- Runtime dependencies installed in this checkout: Node `24.19.0`, npm `11.17.0`, `@deepseek-ai/cordis` `4.0.5`, and DeepSeek protocol/gateway packages `0.2.1-rc.3`.

The checked-in runtime evidence establishes the Host contract used by this work: `agent/created`, `tools/pre-execute`, `tools/result`, and required `systemPrompt.context()` providers; prompt contexts are refreshed again for retries. The source package does not include a local Desktop Host implementation, so its lifecycle behavior is kept as evidence rather than guessed.

## B01–B04 implementation record

- Schema v2 adds `session_bindings`, `contract_candidates`, and `tool_operations`; task ordering/activity metadata is additive.
- Opening a v1 marker first creates `memory.sqlite.v1-backup` (including WAL sidecars when present), then migrates in a transaction and updates the marker only after success.
- Workspace identity hashes the canonical project/worktree root, not a subdirectory launch path.
- Multiple unfinished tasks now return `TASK_SELECTION_REQUIRED`; a session binding or exactly one unfinished task is required to resume.
- `memory_commit` hides revision/lease/fence mechanics. Legacy lower-level tools are available only under `compatibilityTools`.
- Recovery rendering is deterministic, field-prioritized, and limited to 6,000 UTF-8 bytes. It never emits raw events or evidence JSON.

## Verification performed

`npm run check` and `npm test` run with the repository test-isolation setting. The v0.3 suite includes a handcrafted v1 database migration sample, distinct session bindings, canonical subdirectory identity, bounded rendering, and candidate acceptance.

No Desktop profile was changed and no paid model call was made.
